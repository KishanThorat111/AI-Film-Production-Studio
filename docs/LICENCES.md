# Licences of material

The studio keeps one record per version of a source's terms (Library page). Each right is yes, no or unclear; unclear counts as no. A finished film refuses material whose terms the user has not read and confirmed.

| Source | In a film | Reuse in other films | Note |
|---|---|---|---|
| Made in the studio (procedural sound, engine graphics, own recordings) | yes | yes | – |
| ElevenLabs speech, paid plan | yes | yes | not for models labelled beta |
| ElevenLabs sound effects | yes | unclear | kept in the film they were made for; not in the shared library |
| ElevenLabs music, self-serve plans | no | no | blocked: the terms exclude film |
| Gemini app video | yes | yes | watermark; disclose AI use |
| Google, OpenAI, Black Forest Labs images by API | yes | yes | see the record for each |
| Sonniss GDC | yes | yes | no redistribution as effects, no AI training |
| CC0 | yes | yes | check each item's own page |
| CC BY | yes | yes | credit, link and changes must be shown; added to the description by the release package |

These are working notes with dates, not legal advice. Read the terms themselves before confirming a record.
